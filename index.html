Formulario Certamen 3 (2026-2)

Leyes Fundamentales: $$\Lambda_B = \oint \vec{B}\cdot d\vec{l} = \mu_0 I_{enl}$$ $$\varepsilon_{ind} = \oint \vec{E}_{ind}\cdot d\vec{l} = -\frac{d\phi_B}{dt}$$ $$\phi_B = \iint \vec{B}\cdot d\vec{A} \quad ; \quad I = \iint \vec{J}\cdot d\vec{A}$$ $$d\vec{B} = \frac{\mu_0}{4\pi} \frac{I d\vec{l}\times \hat{r}}{r^2}$$
Elementos de Circuito y Campos Canónicos: $$\varepsilon_L = -L\frac{di}{dt} \quad ; \quad \varepsilon_C = \frac{q}{C} \quad ; \quad \varepsilon_R = iR$$ $$B = \frac{\mu_0 I}{2\pi r} \quad ; \quad B = \mu_0 n I$$ $$U_L = \frac{1}{2} L I^2 \quad ; \quad U_C = \frac{1}{2} \frac{Q^2}{C}$$ $$\mu_0 = 4\pi \times 10^{-7}\ \left[\frac{\text{H}}{\text{m}}\right]$$
Inductancia Mutua: $$M = \frac{N_2 \phi_{12}}{I_1} = \frac{N_1 \phi_{21}}{I_2}$$ $$\varepsilon_1 = -M \frac{dI_2}{dt} \quad ; \quad \varepsilon_2 = -M \frac{dI_1}{dt}$$
Parámetros de Circuitos: $$\tau_C = RC \quad ; \quad \tau_L = \frac{L}{R} \quad ; \quad \alpha = \frac{R}{2L}$$ $$\omega_0 = \frac{1}{\sqrt{LC}} \quad ; \quad \omega' = \sqrt{\omega_0^2 - \alpha^2} \quad ; \quad L = \mu_0 n^2 l A$$

Regímenes RLC:
• $\alpha < \omega_0$: subamortiguado
• $\alpha = \omega_0$: críticamente amortiguado
• $\alpha > \omega_0$: sobreamortiguado

Integrales Útiles del Formulario: $$\int \sin^2\theta d\theta = \frac{\theta}{2} - \frac{\sin 2\theta}{4}$$ $$\int \cos^2\theta d\theta = \frac{\theta}{2} + \frac{\sin 2\theta}{4}$$ $$\int \cos\theta \sin\theta d\theta = -\frac{1}{2}\cos^2\theta$$ $$\int \frac{1}{a^2 + x^2} dx = \frac{1}{a} \arctan\left(\frac{x}{a}\right)$$ $$\int \frac{1}{\sqrt{a^2 - x^2}} dx = \arcsin\left(\frac{x}{a}\right)$$ $$\int \frac{1}{\sqrt{a^2 + x^2}} dx = \ln\left(x + \sqrt{x^2 + a^2}\right)$$ $$\int \frac{1}{(a^2 + x^2)^{3/2}} dx = \frac{x}{a^2 \sqrt{x^2 + a^2}}$$ $$\int \frac{x}{a - x} dx = -x - a\ln(a - x), \quad a > x$$ $$\int \frac{x}{(a^2 + x^2)^{3/2}} dx = -\frac{1}{\sqrt{x^2 + a^2}}$$ $$\int \frac{x^2}{(a^2 + x^2)^{3/2}} dx = \ln\left(x + \sqrt{a^2 + x^2}\right) - \frac{x}{\sqrt{a^2 + x^2}}$$
Ecuaciones Diferenciales y Soluciones Exactas:

Carga RC:

$$\mathcal{E} - R\frac{dq}{dt} - \frac{q}{C} = 0 \iff q(t) = Q_{\max}(1 - e^{-t/RC})$$

Crecimiento RL:

$$\mathcal{E} - iR - L\frac{di}{dt} = 0 \iff i(t) = I_{\max}(1 - e^{-(R/L)t})$$

Descarga RC:

$$-R\frac{dq}{dt} - \frac{q}{C} = 0 \iff q(t) = Q_0 e^{-t/RC}$$

Decaimiento RL:

$$-iR - L\frac{di}{dt} = 0 \iff i(t) = I_0 e^{-(R/L)t}$$

Oscilación LC Libre:

$$-L\frac{d^2q}{dt^2} - \frac{q}{C} = 0 \iff q(t) = Q_0 \cos(\omega_0 t)$$

Oscilación RLC Subamortiguada:

$$-L\frac{d^2q}{dt^2} - R\frac{dq}{dt} - \frac{q}{C} = 0 \iff q(t) = Q_0 \frac{\omega_0}{\omega'} e^{-\alpha t} \cos\left(\omega' t - \arctan\left(\frac{\alpha}{\omega'}\right)\right)$$
